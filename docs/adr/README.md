# Architecture Decision Records (ADRs)

Short, permanent notes for naming and data-model choices that would otherwise get re-litigated in code review or agent sessions.

| ADR | Title | Status |
|-----|-------|--------|
| [0001](./0001-spot-encoding-field-name.md) | Rename `completion` → `spotEncoding` | Accepted |

**Format:** Context → Decision → Consequences → Alternatives rejected.

**When to add one:** cross-cutting rename, Hudl vs HuddleStat boundary, or terminology that collides with football jargon.
